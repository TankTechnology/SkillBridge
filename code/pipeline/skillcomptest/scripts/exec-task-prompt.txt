Before executing, record the actual platform environment:

### 3. Execute with platform awareness

Execute the task on $PLATFORM. Pay attention to:
- Does the task fail because of a platform-specific assumption in the SKILL?
- Does the task work correctly on $PLATFORM?
- Does the task produce meaningful blocked/unsupported when appropriate?

Skill source resolution rules:
- If the task or guide names a skill wrapper script, resolve it from the skill
  source first, especially `$SKILL_DIR/scripts/<script>`.
- If `$SKILL_DIR/scripts/<script>` exists but is not executable, you may invoke
  it through the declared shell/interpreter and record that evidence.
- Do not assume skill scripts are on PATH unless the skill guide or metadata
  explicitly says they are installed as commands.
- Only classify a wrapper as missing after checking the resolved skill source
  path and recording the exact path checked.
- If execution requires installing packages or building a local project from the
  skill source, copy the relevant files to `$EXEC_OUT/tasks/$TASK_ID/` first and
  run the install/build there.

CRITICAL RULES for task_metrics.json:
