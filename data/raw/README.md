# Raw experiment records

This directory contains source observations, reviewed record rows, replay task
records, and repair manifests used by the SkillBridge pipeline. Aggregate
paper summaries and paper-specific table/figure renderers are intentionally
kept out of this release.

The raw execution archives, databases, browser caches, skill-package bundles,
and agent transcripts remain outside the Git working tree. The included text
records have been scrubbed for host paths, email addresses, and credential-like
values before publication. The row structure and observation values
are retained.

The row-level release includes the 207 strict issue labels, 205 reviewed repair
cohort rows, 175 target replay cells, and the underlying Linux, macOS, and
Windows replay records used to recover the paper's RQ2 totals.
